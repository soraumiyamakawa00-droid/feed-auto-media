# 営業戦略（社内限定）

## 1. 「デジモンを開発した会社」の整理

ここを間違えるとアポが取れないので、先に事実を押さえます。

| 会社 | 役割 | この提案での位置づけ |
|---|---|---|
| **株式会社ウィズ（WiZ）** | 1996年に『デジタルモンスター』を**企画・原案** | 原点の発明者。ただし玩具企画が主軸で、PCアプリ事業の意思決定者ではない可能性 |
| **株式会社バンダイ** | 1997年6月26日に**発売**。IPの権利主体 | **ライセンス許諾の最終判断者。本命** |
| **バンダイナムコエンターテインメント** | ゲーム化・デジタル事業 | デジタル製品としての事業パートナー候補 |
| **東映アニメーション株式会社** | TVアニメ『デジモンアドベンチャー』以降の**アニメ制作** | 「アニメーション会社」に当たるのはここ。映像IPの窓口 |

> 補足: 権利表記の「本郷あきよし」はウィズとバンダイの共同ペンネーム（ハウスネーム）です。
> つまり**原作権はウィズ＋バンダイに分散している**前提で話を進めてください。

### 推奨アプローチ順

```
1st  バンダイ（または バンダイナムコエンターテインメント）
     → ライセンスと事業化の意思決定ができる。ここが本丸

2nd  東映アニメーション
     → 「アニメ会社に売りたい」という要望に最も合致。
        映像IP側からの切り口。新規事業/ライセンス部門へ

3rd  ウィズ
     → 原点のリスペクトとして接触する価値はあるが、
        単独では事業化の決裁が降りにくい
```

### ただし ── 最初の1社をデジモンにする是非

**リスク**: 大手IPは初回提案で「実績は？」と必ず聞かれます。実績ゼロで最大手に当てると、
一度断られたIPには2〜3年入り直せません。

**推奨する順番**:

| 順 | ターゲット | 目的 |
|---|---|---|
| 0 | **自社オリジナルキャラ or 権利がゆるいIP** | 実物のデモを作る。ここが最優先 |
| 1 | 中堅アニメ制作会社・VTuber事務所・ゲーム会社 | 1社目の導入実績を作る |
| 2 | **デジモン（バンダイ／東映アニメーション）** | 実績を持って本命へ |

> どうしても最初にデジモンへ行くなら、**デモだけは必ず用意してから**行ってください。
> 資料だけの提案は、この規模の会社ではほぼ通りません。

## 2. 当てるべき部署・役職

| 会社タイプ | 部署 | 役職 |
|---|---|---|
| IPホルダー（バンダイ等） | ライセンス事業部 / 新規事業開発 / デジタル事業 | 部長〜課長クラス |
| アニメ制作（東映アニメーション等） | 事業推進 / ライセンス / 新規事業 / DX推進 | 同上 |
| ゲーム会社 | 新規事業 / R&D / IP戦略 | 同上 |

**避けるべき窓口**: 総合お問い合わせフォーム（ほぼ届かない）、制作部門（決裁権なし）

**有効な接点**:
1. 展示会・カンファレンス（AnimeJapan、東京ゲームショウ、Licensing Japan、AI系イベント）
2. 共通の知人・投資家・取引先からの紹介
3. LinkedIn / X での担当者への直接接触
4. プレスリリースで話題を作り、向こうから来てもらう

## 4. 初回商談トークスクリプト（30分）

### 掴み（2分）
> 「1997年に、小さな画面の中で生き物を育てる体験を発明されたのが御社です。
> あの体験を、いまのPCとAIでもう一度やりませんか、というご提案です。」

### 課題提起（3分）
> 「いまIPホルダーの皆さまが直面しているのは、新作の間の"端境期"にIPが沈黙すること、
> そして生成AIとの距離の取り方だと認識しています。
> 後者については、ひとつだけ確かなことがあります。
> **公式が出さなければ、非公式が出ます。** 先に公式が出すことが、いちばん強い防御です。」

### デモ（10分）
> 実際に動くものを見せる。説明より先に動かす。

### 仕組み（5分）
> 「ガワは御社、中身は Addness という AI行動支援OS です。
> キャラクターAIを一から作ると雑談はできますが、生活は変えられません。
> Addness は既に"人の行動を変える"部分が動いています。
> 実装は Claude Code で回しているので、監修のご指摘は**その日のうちに直して再提示**できます。」

### 懸念の先回り（5分）
> 「キャラクターを壊されるのが怖い、というのが最大のご懸念だと思います。
> 挨拶や励ましは**監修済みの固定セリフ**を優先し、AIの生成は補完に回します。
> 生成の前後に二段のフィルタを入れ、全応答をログに残します。
> そして**御社にはいつでも止める権利**を契約に明記します。」

### クロージング（5分）
> 「いきなり大きな契約はお願いしません。
> **3〜4週間、キャラクター1体のPoC**から始めさせてください。
> 御社の工数は会議3回だけです。実機を見てから続きをご判断ください。」

## 5. 想定反論への即答（詳細は 04-faq-risks.md）

| 反論 | 一言返し |
|---|---|
| 「実績は？」 | 「本件が1社目です。だからこそ**当社負担のPoC**からご提案しています」 |
| 「AIにキャラを演じさせるのは…」 | 「全部は演じさせません。監修済みセリフが主、生成は補完です」 |
| 「Desktop Mate があるのでは」 | 「あれは"いる"アプリです。本件は"行動を変える"アプリで、レイヤーが違います」 |
| 「社内でもできる」 | 「できます。ただ**24ヶ月分の人員**を今から確保されますか、という話です」 |
| 「誰に相談すれば」 | 「ライセンスと新規事業の両方に関わる方が理想です。ご紹介いただけますか」 |

いきなりで恐縮ですが、本題から書かせてください。

御社が1997年に世に出された『デジタルモンスター』が提示していた構想

これは玩具の仕様ではなく、いま世界中の企業が「AIエージェント」という名前で
追いかけているものそのものだと考えています。

常時起動のPC、自然言語での対話、文脈を理解するAI、

の2点です。開発も販売も収益も、御社のものになる座組みを想定しています。

自社オリジナルキャラクターで実装した参考機を、実機でご覧いただけます。
30分ほどお時間をいただけないでしょうか。

ご多忙のところ恐縮ですが、ご検討いただけますと幸いです。

## 5. 返信が来たときの次の一手

| 返信内容 | 次のアクション |
|---|---|
| 「詳細資料を」 | `01-proposal.md` を10枚スライドに要約して送付。**同時に日程候補を3つ出す** |
| 「どういう座組み？」 | **最重要の反応。**A/B/C案の表（01-proposal 第6章）を送り、すぐ打ち合わせへ |
| 「担当部署に転送」 | 1週間後にフォロー。転送先が分かれば直接お礼を送る |
| 「時期ではない」 | 「いつ頃であればよいか」を必ず聞く。3ヶ月後にリマインド設定 |
| 「見送り」 | 理由を1つだけ聞く。素材として次の提案に活かす |
| 無反応 | 1週間後に1回だけフォロー。それ以上は追わない |

# デジモンに、時代が追いついた。— 提案書一式

> **「IPを貸してください」ではなく「御社が開発して、御社が売ってください」。**

1997年の『デジタルモンスター』が提示した構想を、いまのPCとAIで完全な形で実装する。
開発・販売・収益はすべてIPホルダー側に残し、当社は
**Addness（AI行動支援OS＝キャラクターの中身）** と
**Claude Code（監修の往復を即日で回す開発手法）** を提供する立場に立つ。

作成日: 2026-09-22 ｜ 想定初回送付先: デジタルモンスターの企画・開発・映像化に関わる各社

## 提案の骨格

```
1997年の構想        デバイスの中に生き物が住み、世話をすると育ち、姿が変わる
      ↓
足りなかった5つ      器 / 対話 / 知能 / 育成の材料 / つながり
      ↓
2026年、全部揃った   常時起動PC / 自然言語 / LLM / 実生活データ / 常時オンライン
      ↓
だから              御社が作るべき。当社は中身と作り方を売る
```

## 使い方

1. **`03-sales-strategy.md` の Step 0 を先に終わらせる** — ロウの参考機を動かす。ここが全ての前提
2. `05-outreach-templates.md` の文面でアポを取る
3. 初回商談は `03-sales-strategy.md` のトークスクリプト通りに。**立ち位置の表明（第5パート）が勝負どころ**
4. 二次商談で `02-roadmap.md` を出し、Phase 0 の発注につなげる

## 必ず聞かれる質問

**「そんなにいい話なら、なぜ御社がやらないんですか？」**
→ 回答は `04-faq-risks.md` の **Q0**。一字一句固めてから商談に行くこと。

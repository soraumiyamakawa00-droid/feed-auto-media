# デスクトップ・キャラクターAI 提案書一式

**「アニメのキャラクターが、PCの中で生きて、ユーザーの毎日を動かす」**
Addness（AI行動支援OS）× Claude Code × 御社IP による共同事業のご提案。

作成日: 2026-09-22 / 想定初回送付先: デジタルモンスターの企画・開発・映像化に関わる各社

## ファイル構成

| ファイル | 用途 | 誰に見せるか |
|---|---|---|
| [01-proposal.md](01-proposal.md) | 本提案書（コンセプト・体験・事業性・体制） | 先方（新規事業/ライセンス/デジタル事業部） |
| [02-roadmap.md](02-roadmap.md) | アバター開発ロードマップ（Phase 0〜4・24ヶ月） | 先方（技術/制作/経営判断者） |
| [03-sales-strategy.md](03-sales-strategy.md) | 営業戦略・ターゲット整理・トークスクリプト | 社内限定 |
| [04-faq-risks.md](04-faq-risks.md) | 想定質問・反論への回答、権利/リスク整理 | 社内限定（一部は先方提出可） |
| [05-outreach-templates.md](05-outreach-templates.md) | 初回メール・問い合わせフォーム文面 | 社内限定 |

## 使い方

1. `03-sales-strategy.md` でターゲットと当てる部署を決める
2. `05-outreach-templates.md` の文面でアポを取る
3. 初回商談で `01-proposal.md`（要約版・10分）を提示
4. 二次商談で `02-roadmap.md` を出して Phase 0 の PoC 発注につなげる
